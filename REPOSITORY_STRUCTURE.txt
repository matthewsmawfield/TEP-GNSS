KEY DISTINCTIONS
================================================================================

OFFICIAL PIPELINE vs EXPERIMENTAL WORK
--------------------------------------
OFFICIAL PIPELINE:           EXPERIMENTAL WORK:
/scripts/steps/              /scripts/exploratory/
Publication ready            Research & development
Peer-reviewed               Testing new approaches
Stable interfaces           Alternative methods
Well-documented             Future candidates
Grouped (step_1.0-4.5)      Multiple variants

================================================================================
VERSION CONTROL
================================================================================

TRACKED (In Git)
----------------
✅ scripts/steps/        ->  Official pipeline
✅ scripts/utils/        ->  Shared infrastructure  
✅ data/processed/       ->  Pipeline outputs
✅ results/outputs/      ->  Official results
✅ results/figures/      ->  Publication figures
✅ site/                 ->  Web documentation
✅ theory/               ->  Theoretical documentation
✅ logs/                 ->  Execution logs
✅ requirements/         ->  Dependencies

GITIGNORED (Not Tracked)
------------------------
🚫 scripts/exploratory/  ->  Experimental scripts
🚫 data/exploratory/     ->  Experimental data
🚫 results/exploratory/  ->  Experimental results
🚫 data/raw/*/          ->  Large raw files
🚫 results/tmp/         ->  Temporary files

================================================================================
BENEFITS
================================================================================

Clear Separation
- Production vs Research code clearly separated
- Official pipeline ready for publication
- Experimental work isolated for development

Scalable Architecture
- Sequential pipeline (step_0 -> step_18)
- Modular design - easy to extend
- Research-friendly - supports experimentation

Workflow
EXPLORATORY -> OFFICIAL PIPELINE -> PUBLICATION
(Research)   (Validation)        (Manuscript)
