4.2.2 Processing Independence: Convergence Across Divergent Methodologies

A critical concern is whether the observed correlations could arise from common processing artifacts shared across the "independent" analysis centers. This possibility must be systematically addressed, as it represents one of the most sophisticated counter-arguments to our findings.

Fundamental Processing Philosophy Differences

The three analysis centers employ fundamentally different processing philosophies that would be expected to produce different artifacts if the signal were methodological in origin:

Network Solutions vs. Precise Point Positioning
  • CODE (Network Solution): Uses double-differenced observations across the entire global network simultaneously. This approach forms baselines between stations, solving for positions, orbits, and clocks in a unified network adjustment. The solution is inherently global and relies on relative measurements between stations.
  • ESA/JPL (Precise Point Positioning): Processes each station independently using undifferenced observations. This approach treats each receiver as an isolated entity, solving for position and clock offset without explicit reference to other stations. The solution is fundamentally local, station-by-station.
  • IGS (Multi-Center Combination): Combines solutions from multiple analysis centers using weighted averaging. This represents a meta-analysis rather than an independent processing approach, though it includes contributions from centers with diverse methodologies.

Critical implication: Network solutions and PPP represent philosophically opposite approaches to GNSS processing. Network solutions depend on inter-station connectivity for their solution, while PPP explicitly avoids it. A processing artifact that manifests identically in both approaches would require a shared systematic error at a deeper level (e.g., orbit models or physical constants), which leads to the next consideration.

Differential Station Coverage Across Centers

While all centers process data from the same IGS global tracking network, the specific stations selected and data quality criteria differ between centers, resulting in partially overlapping but distinct station subsets. This provides additional validation:

  • Different station selections: Each center applies independent quality control and data availability criteria
  • Different temporal coverage: Varying data availability across centers creates partially independent datasets
  • Independent processing decisions: Station weighting, outlier rejection, and solution strategies differ between centers

Key observation: Despite using different processing philosophies (network vs. PPP), different software implementations, and different station subsets from the shared IGS network, all three centers converge on λ = 3,330-4,549 km (CV = 13.0%). This convergence across independent processing solutions is the signature of genuine physical phenomena, not processing artifacts.

Why Common Artifacts Are Unlikely

For a processing artifact to explain our observations, it would need to:

  1. Survive philosophical differences: Manifest identically in both network solutions (globally coupled) and PPP (station-independent)
  2. Cross network boundaries: Produce the same correlation length in two completely independent physical networks (CODE vs. IGS/ESA stations)
  3. Survive scrambling: Persist through distance, phase, and station randomization (comprehensive validation observes 15-42× signal destruction across multiple approaches)
  4. Show physical dependencies: Exhibit systematic variations with elevation, orbital velocity, and gravitational fields—characteristics unexpected from software artifacts

Convergence despite divergence: The observed multi-center consistency (CV = 13.0%) across these methodological and network differences provides compelling evidence that the signal is physical rather than artifactual. If processing artifacts were responsible, we would expect center-specific values of λ reflecting their different systematic vulnerabilities, not convergence on a common physical parameter.

Conclusion: While TIDs operate in an overlapping frequency band, the observed signals are distinguished through (1) spatial structure incompatibility (plane-wave vs exponential decay), (2) survival through aggressive ionospheric processing, (3) independence from space weather drivers, and (4) multi-center convergence on identical correlation lengths.
